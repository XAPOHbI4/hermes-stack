# Jarvis Sales Mentor MVP

Личный Telegram-помощник Василия развивается в трёх направлениях:

1. принимает запись звонка, локально расшифровывает её и присылает живой разбор;
2. ведёт по курсу «Константы 2.0», обсуждает просмотренный урок, помогает выполнить ДЗ и хранит прогресс.
3. готовит методическую базу курса «Продажи в новой реальности» для развития разборов и будущего отдельного наставника.

Репозиторий содержит воспроизводимый код, навыки Hermes и тесты. Секреты, Telegram ID, записи звонков, транскрипты, SQLite-базы и полные материалы курса в Git не входят.

## Разбор звонков

Поток: `Telegram → SQLite-очередь VPS → локальный Whisper на Mac → LLM-анализ → Telegram`.

- Повторная загрузка определяется по SHA-256.
- Этапы STT и анализа сохраняются между попытками.
- После неоднозначной доставки автоматическая повторная отправка запрещена.
- Разбор проверяет свои цитаты по транскрипту, но не показывает их пользователю.
- До пяти прежних разборов и подтверждённых исходов участвуют в поиске повторяемых паттернов.
- Стереозапись размечается по каналам; это не идентификация людей.

Код и systemd unit находятся в [`call-review/`](call-review/). Конфигурация и credentials читаются из уже настроенного Hermes.

## Наставник по курсу

Поток: `название урока → полный просмотр → обсуждение → ДЗ → интервал → следующий урок`.

- 7 основных уроков с интервалом минимум 3 дня.
- 3 гостевых эфира с интервалом минимум 2 дня.
- Следующий урок закрыт до завершения обсуждения и ДЗ.
- Ответы и прогресс сохраняются в SQLite.
- Напоминание запускается штатным cron Hermes.
- Авторские утверждения отделяются от фактов; рискованные психологические и финансовые упражнения не назначаются автоматически.

Код и навык находятся в [`course-mentor/`](course-mentor/). Полные субтитры намеренно исключены из публичного репозитория. На личной машине они подключаются командой:

```powershell
python course-mentor/scripts/build_sources.py --source "D:\path\to\Константы 2.0"
```

Скрипт создаёт локальные `references/source/` и `references/manifest.json`, проверяемые по SHA-256. Эти файлы игнорируются Git.

## Продажи в новой реальности

Каталог [`sales-reality-course/`](sales-reality-course/) содержит 55 исходных файлов курса, проверяемую карту 21 расшифровки и двух запланированных разделов, производную методику для Джарвиса, правила оценки эмоциональной динамики и поэтапный план внедрения. Исходники можно обновить командой:

```powershell
python sales-reality-course/scripts/build_sources.py --source "D:\path\to\Продажи в новой реальности"
```

Импорт сохраняет структуру и SHA-256 всех файлов в `references/manifest.json`.

## Проверка

```powershell
python -m unittest discover -s call-review/tests -v
python -m unittest discover -s course-mentor/tests -v
```

Текущий масштаб — один владелец, одна последовательная очередь и один Mac STT worker. Исходы звонков нужно заполнять вручную; без этого улучшение продаж нельзя измерить.
