# Продажи в новой реальности

Этот каталог описывает, как использовать курс Виталия Голицына в личном Джарвисе Василия.

В репозитории находятся:

- `references/course-map.json` — порядок, длительность и назначение 21 урока;
- `references/method.md` — методика разбора звонков, извлечённая из курса и адаптированная под автомобильные продажи;
- `emotion-analysis.md` — границы и схема оценки эмоциональной динамики клиента;
- `integration-plan.md` — этапы разработки и проверяемые критерии готовности;
- `references/source/` — 55 исходных файлов курса с сохранённой структурой папок;
- `references/manifest.json` — размеры и SHA-256 исходных файлов;
- `scripts/build_sources.py` — обновление исходных файлов и манифеста.

Полные субтитры, презентации и задания хранятся в репозитории. Скрипт обновляет их из исходной папки и пересобирает манифест.

```powershell
python scripts/build_sources.py --source "C:\Users\...\Продажи в новой реальности"
```

Курс содержит 21 уникальную расшифровку общей длительностью 27 часов. Урок 4 будет добавлен позднее, а урок 8 используется как отдельная итоговая работа.
